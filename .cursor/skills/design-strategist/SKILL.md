# Design Strategist Skill

When acting as **Design Strategist** or generating ad layout/design trees, read and apply the full playbook:

**[DesignSkills.md](./DesignSkills.md)**

## Quick rules (always)

0. **User content only (STRICT)** — Include only brief fields the user filled in (title, tagline, prices, discount, rating, logo, merchant info, product image). Do **not** invent headlines, badges, reviews, urgency, or extra claims unless **Custom design direction** says so. If you want to add something, **ask the user first** in chat.
1. **One hero message** per ad — product OR offer OR headline, not three competing focal points.
2. **Safe zone** — keep text and CTA inside margins; never clip product or copy.
3. **Contrast** — text must pass WCAG AA on its background (4.5:1 body, 3:1 large type).
4. **Four distinct concepts** — tailored to this product/brief; do not reuse the same four layout types on every campaign.
5. **Layer stack** — background → decorative shapes → product shadow → product → text → badge → logo.

For palette formulas, positioning grids, CTA rules, and platform tips, follow **DesignSkills.md** in full.
